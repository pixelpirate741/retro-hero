# 🕹️ RETRO HERO

A fast-paced retro pixel platformer built with Python + Pygame. Now works on both tablet and PC with auto-scaling!

### 🎮 How To Play (Friends - 2 steps)

1. Download ZIP: Click green **Code** button -> **Download ZIP**
2. Extract and run `main.py` 


### 🕹️ Controls

- **Arrow Keys / A-D:** Move
- **SPACE / W / UP:** Jump
- **Touch:** On-screen D-Pad + Jump button (auto-appears on tablet)
- **R:** Restart when game over
- **ESC:** Quit

### ✨ Features

- Auto-scales to any screen (Tab / Laptop / PC) - 1280x720 base
- Touch controls for Android tablets
- Resizable window + pixel-perfect scaling
- Retro sound & particle effects
- wise range of enemies and attack button

### 🛠️ Built With

- Python 3
- Pygame
